LANGGRAPH:

Create a LangGraph StateGraph with shared AgentState containing:

- issue_id
- repository
- issue_title
- issue_description
- relevant_files
- code_context
- root_cause
- proposed_fix
- test_results
- security_results
- confidence
- current_agent
- progress
- retry_count
- approval_required
- status

Create nodes for:

1. supervisor
2. analyze_repository
3. locate_code
4. find_root_cause
5. generate_fix
6. run_tests
7. security_review
8. human_approval
9. finalize

Add conditional routing:
- If tests fail → return to fix generation
- Maximum 3 retries
- If security risk is high → require human approval
- If everything passes → move to approval/finalization

Create tools:

For now, tools can use mock/local implementations but keep them separated so GitHub API and sandbox execution can be connected later.

FASTAPI ENDPOINTS:

GET /health

POST /api/ai/analyze
Start an AI investigation for an issue.

POST /api/ai/run
Run the complete LangGraph workflow.

GET /api/ai/runs/{run_id}
Return current agent status, progress, root cause, test results, and security results.

POST /api/ai/runs/{run_id}/approve
Resume the workflow after human approval.

POST /api/ai/runs/{run_id}/reject
Reject the proposed fix.

Use Pydantic request/response models.

RESPONSE SHOULD INCLUDE:

{
  "run_id": "...",
  "status": "running",
  "current_agent": "root_cause",
  "progress": 65,
  "confidence": 0.91,
  "root_cause": "...",

}
