I have an existing project called "DevFix AI" — an AI-powered software engineering platform that analyzes GitHub repositories, investigates bugs, performs root-cause analysis, generates code fixes/patches, runs tests in a sandbox, and uses LangGraph-based AI agents.

I want you to upgrade the existing application by adding a GLOBAL, CONTEXT-AWARE AI ASSISTANT across the entire application.

IMPORTANT:
- First inspect the existing codebase and understand the current architecture.
- Do NOT rewrite the application from scratch.
- Do NOT remove or break existing features.
- Reuse existing APIs, components, agents, database models, authentication, GitHub integration, and LangGraph workflows wherever possible.
- Follow the existing project structure, naming conventions, UI style, and coding patterns.
- Before implementing, identify where the current AI agents, API routes, frontend layout, and state management are located.

3. CONTEXT AWARENESS
==================================================

The assistant must understand the current application context.

Example context:

{
  page: "investigation",
  repository: "backend",
  investigationId: "123",
  pullRequestId: null,
  issueId: "456"
}

Pass only relevant context to the backend.

The assistant should NOT require the user to repeatedly explain what repository or investigation they are talking about.
