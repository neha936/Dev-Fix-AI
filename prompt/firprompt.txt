3. REAL INVESTIGATION
================================

When user clicks "Start Investigation":

Send the real repository + issue to FastAPI/LangGraph.

Workflow:

GitHub Issue
    ↓
Supervisor Agent
    ↓
Clone repository to isolated workspace
    ↓
Analyze repository structure
    ↓
Read relevant source files
    ↓
Search for error/root cause
    ↓
Reproduce bug when possible
    ↓
Generate actual code fix
    ↓
Apply patch to workspace
    ↓
Run repository tests
    ↓
If tests fail → analyze failure → fix again
    ↓
Security review
    ↓
Generate final diff
    ↓
Create Git branch
    ↓
Commit changes
    ↓
Push branch to GitHub
    ↓
Create REAL Pull Request

Maximum 3 fix/test iterations.

================================
4. IMPORTANT: ACTUAL CODE FIXING
================================

The AI must NOT only explain the bug.

It must actually modify the repository files in the isolated workspace.

Before modification:
- inspect repository
- identify relevant files
- understand existing code
- determine root cause

After modification:
- show changed files
- show git diff
- run tests
- report test results

Never claim a fix succeeded if no code was actually changed/tested.

================================

================================

NEVER directly modify main/master.

Create:

git checkout -b branch
→ modify files
→ run tests
→ git add
→ git commit
→ git push
→ create GitHub Pull Request

PR should contain:

Title:

Body:
- Problem
- Root cause
- Changes made
- Tests performed
- Security review
- AI confidence

Return the REAL PR URL.
