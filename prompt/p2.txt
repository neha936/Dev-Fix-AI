Redesign the existing DevFix AI investigation dashboard into a premium, production-grade AI software debugging and autonomous code repair platform.

IMPORTANT:
Do NOT make it look like a normal admin dashboard.
It should visually communicate that this is an AI-powered autonomous debugging system that investigates GitHub issues, understands the repository, identifies root causes, generates fixes, runs tests, performs security analysis, and prepares a pull request.

Keep the existing dark theme and overall brand identity, but significantly improve the information architecture, functionality visibility, interactions, and visual hierarchy.

20. IMPORTANT FUNCTIONALITY
==================================================

Do not create static-looking UI only.

Where backend functionality already exists, connect the UI to the existing APIs.

The UI should clearly represent:

GitHub Issue
→ Repository
→ AI Investigation
→ Code Analysis
→ Root Cause
→ Fix Generation
→ Patch
→ Test Execution
→ Security Audit
→ Verification
→ Human Approval
→ Pull Request

If a backend API is not available for a feature, create a clean mock/service abstraction rather than pretending that the feature is actually connected.

Keep the existing project structure and avoid unnecessary breaking changes.

Make the final result look like a production-ready autonomous software engineering platform, not a generic admin dashboard.
